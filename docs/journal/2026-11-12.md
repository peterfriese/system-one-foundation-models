### 2. Live API Verification Discoveries (`POST /v1beta/decisions`)
- **`usage.total_input_tokens` Wire Key Support**:
  - Live responses from `https://generativelanguage.googleapis.com/v1beta/decisions` return input token telemetry under `"usage": { "total_input_tokens": <Int> }` in addition to `"input_tokens"` or `"usageMetadata"`.
  - Extended `GeminiDecisionsResponse.Usage` in `GeminiDecisionsWireDTOs.swift` to decode `total_input_tokens`, `input_tokens`, and `promptTokenCount` seamlessly.
- **Flat Typed Multimodal `input` Items (`type: "text"` / `type: "image"`)**:
  - Live testing revealed that `/v1beta/decisions` rejects `generateContent`-style `[{"role": "user", "parts": [{"text": ...}, {"inline_data": ...}]}]` wrappers with HTTP 400 (`The 'type' parameter is required at 'input[0]'`) and rejects `"image_url"` (`Supported values: 'audio', 'document', 'image', 'text', 'video'`).
  - Updated `GeminiDecisionsRequest.InputPayload.ContentItem` and `GeminiDecisionsPayloadAdapter` to serialize multimodal inputs as a flat array of typed items:
    - Text item: `{"type": "text", "text": "..."}`
    - Image item: `{"type": "image", "mime_type": "image/png", "data": "<raw_base64>"}`
  - Retained backward-compatible decoding for legacy `parts` / `inline_data` structures in `GeminiDecisionsWireDTOs.swift`, and updated `ADR-2026-11-11-01` and `tech-notes/0018-gemini-decisions-api-architecture.md`.

### 3. Multimodal Batch Latency Optimization (`TranscriptAttachmentExtractor`)
- **Problem**: During live 12-email benchmarks in `MailTriageApp`, emails containing synthetic UI screenshot attachments (solid fills, sharp vector text, and diagnostic overlays) suffered ~4.5x payload inflation when unconditionally re-encoded as lossy JPEG (`quality: 0.8`), increasing Base64 upload size and multimodal evaluation latency. Furthermore, comparing PNG and JPEG previously risked downscaling the source `CGImage` twice.
- **Fix**:
  - Refactored `TranscriptAttachmentExtractor.extractImage(from:)` in `Sources/SystemOneCore/Attachment/TranscriptAttachmentExtractor.swift` to downscale the `CGImage` at most once (`downscaleCGImage(_:maxDimension: 1024)`).
  - Encodes the downscaled image to both PNG (`encodePNG`) and JPEG (`encodeJPEG`) in memory and automatically selects whichever representation produces the smaller byte payload (`png.count <= jpeg.count ? .png : .jpeg`).
  - Added unit coverage in `ClefLanguageModelTests` verifying compact format selection on synthetic graphics vs. photographic noise, reducing live 12-email multimodal benchmark latency to **~404ms p50** (with 100% classification accuracy and `0` output tokens).

## 🚧 Challenges & Solutions

### 1. Live `/v1beta/decisions` Multimodal Schema Divergence from `generateContent`
- **Challenge**: Google's conversational `generateContent` API wraps multimodal inputs in `[{"role": "user", "parts": [{"text": ...}, {"inline_data": ...}]}]`, whereas the live `/v1beta/decisions` endpoint requires flat discriminated union objects (`{"type": "text", ...}` and `{"type": "image", "mime_type": ..., "data": ...}`).
- **Solution**: Updated `GeminiDecisionsRequest.InputPayload.ContentItem` to encode the flat `"type": "text"` and `"type": "image"` wire format while keeping decoder support for legacy `parts` arrays so existing fixtures and gateway payloads decode cleanly.

### 2. Synthetic Attachment Bloating in Multimodal Benchmarks
- **Challenge**: Re-encoding `CGImage` attachments exclusively as JPEG inflated sharp UI screenshots by ~4.5x compared to lossless PNG, penalizing upload serialization and network transfer times.
- **Solution**: Implemented single-pass `downscaleCGImage` followed by compact byte-size selection between `encodePNG` and `encodeJPEG` in `TranscriptAttachmentExtractor`.

### 3. Process-Global Environment Mutation in Parallel Swift Testing
- **Challenge**: Calling `setenv("GEMINI_API_KEY", ...)` and `unsetenv` inside unit tests risks data races under Swift Testing's parallel runner and violates strict concurrency safety.
- **Solution**: Added `internal var environmentOverride: [String: String]?` to `GeminiDecisionsHTTPBackend`, allowing hermetic, thread-safe testing of `GEMINI_API_KEY` $\to$ `GOOGLE_API_KEY` fallback priority without mutating process state.
