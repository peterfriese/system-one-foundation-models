## 🔨 Implementation Trajectory

### 1. `InspectionHUDView` Overhaul & Emil Design Engineering Polish
- **Eliminated HUD Layout Pumping**:
  - In dynamic inspection UIs, transitioning between `.idle`, `.analyzing`, `.result`, and `.error` states often causes vertical height shifts ("pumping") that jar user focus and disrupt camera viewfinder alignment.
  - Overhauled `InspectionHUDView.swift` to enforce a strict, fixed 144pt height container across all four states (`.frame(height: 144)`).
  - Applied smooth crossfade transitions (`.transition(.opacity.combined(with: .scale(scale: 0.98)))`) within the fixed container bounds.
- **Symmetrical 48pt Glass Action Buttons**:
  - Replaced asymmetric button styles with balanced 48pt high touch targets (`.frame(height: 48)`) following Emil Kowalski's micro-interaction standards.
  - Primary capture button uses prominent accent tinting and active haptic feedback.
  - Secondary reset and configuration buttons share identical 48pt height and curved corner geometry with `.ultraThinMaterial` Liquid Glass styling.
- **Pixel-Matched Top Bar Controls (36pt)**:
  - Pixel-matched the top controls bar to an exact 36pt height (`.frame(height: 36)`).
  - Aligned backend picker dropdown menu and real-time latency telemetry pill (`server-timing` ingestion) to 36pt with consistent padding, iconography, and typographic baseline.

## 🚧 Challenges & Solutions

### 1. View Height "Pumping" in Camera HUD
- **Challenge**: Switching between camera viewfinder states (scanning $\to$ analyzing $\to$ result badge $\to$ error) caused varying height changes in the HUD overlay, resulting in distracting layout shifts ("pumping") that obstructed camera visibility.
- **Solution**: Refactored `InspectionHUDView` with an explicit fixed container frame of 144pt (`.frame(height: 144)`). Content views within each state are vertically centered inside this invariant space, completely stabilizing the camera viewfinder presentation.

### 2. Button Visual Hierarchy & Touch Target Symmetry
- **Challenge**: Differing button heights (38pt vs. 50pt) and text labels caused visual imbalance across the HUD bottom bar.
- **Solution**: Standardized all primary and secondary action buttons to identical 48pt heights (`.frame(height: 48)`) with matching corner radii and subtle glass materials, creating harmonious visual rhythm compliant with Apple HIG and Emil design engineering guidelines.

### 3. Top Controls Bar Alignment
- **Challenge**: The model picker dropdown menu and the latency telemetry badge had mismatched vertical paddings and heights, appearing misaligned at the top of the HUD.
- **Solution**: Set an explicit 36pt height container for both elements (`.frame(height: 36)`), matching capsule styling and icon baselines for a unified status bar appearance.
