## 🔨 Implementation Trajectory

### 1. Multi-Turn Metadata Context Bug Resolution (`SystemOneCore`)
- **Problem**: In `ResponseExtensions.swift`, resolving metadata from `LanguageModelSession.Response` iterated forward over `transcriptEntries`. In any multi-turn conversation (e.g. iterative triage, user clarification, chain-of-thought refinement), it always returned the metadata from the **very first turn**, leaking stale latency metrics, confidence values, and calibrated probabilities into subsequent turns.
- **Fix**: Updated `metadata` in `ResponseExtensions.swift` to iterate in reverse (`transcriptEntries.reversed()`), guaranteeing that caller queries always resolve the active turn's metadata. Also purged unused legacy helper `probabilityValue(for:)`.

### 2. Recursive `$ref` Pointer Resolution in Schema Translation (`SystemOneCore`)
- **Problem**: In Apple Foundation Models, optional enums (`MyEnum?`) emit JSON schemas wrapped in `anyOf` with a null variant (`{"anyOf": [{"type": "null"}, {"$ref": "#/$defs/MyEnum"}]}`). `SchemaTranslator.swift` performed non-recursive resolution: it checked for top-level `$ref` pointers *before* unwrapping `anyOf`. When `anyOf` was unpacked, the inner `$ref` was copied to the root dictionary but never dereferenced, leaving the property with an unparsed reference and no enum cases.
- **Fix**: Refactored `resolveProperty(raw:defs:)` to run an iterative resolution loop (bounded up to 10 levels deep) that alternates between unwrapping `anyOf` variants and dereferencing `$ref` pointers. Cleaned up unused convenience method `translateToQuestions(_:)`.

### 3. Rubric Score Probability Mass Preservation (`OpenAIFoundationModels`)
- **Problem**: `OpenAIDecisionsPayloadAdapter.swift` mapped OpenAI rubric score probabilities by `label ?? value` (e.g. `"Low": 0.85`), whereas `SystemOneAnswer.scoreValue(minimum:maximum:isInteger:)` expects stringified integer level indices (`"0"`, `"1"`, etc.). As a result, `Int("Low")` evaluated to `nil`, discarding the entire calibrated probability mass distribution from `ScoreValue`.
- **Fix**: Updated the adapter to key `probsDict` strictly by `$0.value` (the numeric level index), preserving human-readable labels exclusively in `legendDict`.

### 4. Fail-Closed Image Dimension Guardrails (`SystemOneCore`)
- **Problem**: In `SystemOneImage.swift`, `validate()` previously checked dimensions inside an `if let dimensions = Self.extractDimensions(...)` block. If dimension extraction failed or encountered truncated headers, it failed open, bypassing resolution and megapixel limits entirely.
- **Fix**: Replaced with a fail-closed guard: `guard let dimensions = Self.extractDimensions(data: data, format: format) else { throw SystemOneError.modelExecutionError(...) }`. Any image whose dimensions cannot be verified is rejected prior to model ingestion.

### 5. ModernBERT Delimiter Injection Sanitization (`LayaOnDevice`)
- **Problem**: `LayaSequenceBuilder.swift` sanitized only the tokenizer's mask token (`[MASK]`), leaving sequence delimiters (`[SEP]`, `[CLS]`, `<s>`, `</s>`, `<bos>`, `<eos>`) unescaped in user input, allowing malicious inputs to inject token boundaries and manipulate attention heads.
- **Fix**: Introduced `reservedDelimiters` table covering all ModernBERT and RoBERTa control tokens. Added `sanitize(_ text:)` to strip control tokens from instruction text, candidate options, and application state before tokenization. Added `pretokenizeState(_ state:)` to avoid redundant state tokenization in multi-question batches.

### 6. Bounded Subword Matching Eliminating $O(L^3)$ DoS (`LayaOnDevice`)
- **Problem**: In `ModernBERTTokenizer.swift`, the greedy subword matching algorithm evaluated substrings using `stride(from: remaining.count, to: 0, by: -1)` combined with `remaining.prefix(end)` on `Substring`. On continuous strings without spaces (e.g. 5,000 characters), Unicode grapheme cluster counting and repeated string allocations produced $O(L^3)$ complexity, freezing the thread.
- **Fix**: Bounded prefix search length to a maximum of 64 characters (`min(remaining.count, maxSubwordLen)`), cutting search space to $O(L \cdot K)$ and eliminating Catastrophic Tokenization Backtracking.

### 7. Swift 6 Concurrency & Security Hardening
- **Synchronous Core ML Offloaded**: In `LayaCoreMLEngine.swift`, wrapped `executeCoreML(model:sequence:)` in `Task.detached` to prevent blocking the Swift concurrency cooperative pool during Neural Engine / GPU inference.
- **Configuration Mutation Safety**: Cloned caller-provided `MLModelConfiguration` via `.copy()` before mutating `computeUnits = .all`, preventing unexpected side effects on caller configurations.
- **Data Race in Mock Backend**: In `MockOpenAIDecisionsBackend.swift`, synchronized access to `handler` via `lock.withLock` across getter, setter, and evaluation paths.
- **Enforced HTTPS in ProxyTransport**: In `ProxyTransport.swift`, added `validateProxyEndpointSecurity()` requiring `https://` for all remote endpoints and restricting unencrypted `http://` strictly to loopback addresses (`localhost`, `127.0.0.1`, `::1`).
- **Cooperative Cancellation**: Re-threw `CancellationError` and `URLError.cancelled` in `LayaHTTPBackend.swift` instead of wrapping them in generic network errors.
- **Preprocessor Syntax Fix**: Removed orphaned duplicate `#else` / `#endif` block in `FirebaseAppCheckTransport.swift`.
- **Production Logging Hygiene**: Removed raw `print` statements in `OpenAIDecisionsHTTPBackend.swift`.

### 8. UI Stability & Palette Scope Fixes (`ClefCameraScanner` & `NutritionLabelScannerApp`)
- **Infinite Stack Recursion**: In `InspectionHUDView.swift`, `static var amber: Color { .amber }` recursively invoked its own getter until stack exhaustion. Fixed by returning the concrete type `Color.amber`.
- **Color Palette Scoping**: Changed palette declarations from `private` to `extension Color` / `extension ShapeStyle where Self == Color`, resolving scope errors in `CameraPreviewView.swift`.
- **Array Bounds Clamping**: In `SafetyIndicatorBanner.swift`, clamped `decision.allergenRisk` and `decision.processingTier` to `0...3` prior to indexing into 4-element display arrays, preventing `Index out of range` panics on unexpected model outputs.

## 🚧 Challenges & Solutions

### 1. Recursive `$ref` Traversal in Dynamic Schema Generation
- **Challenge**: Apple Foundation Models encodes optional enum choices as an `anyOf` array containing a null type object and a `$ref` pointing into `#/$defs/`. Standard single-pass parsers either dereference before unwrapping (missing the inner ref) or unwrap once without dereferencing (leaving raw pointer strings).
- **Solution**: Implemented an iterative depth-bounded resolution loop that repeatedly unwraps `anyOf` and dereferences `$ref` until the dictionary reaches a stable terminal state or hits `maxDepth = 10`.

### 2. Subword Tokenizer Performance on Pathological Inputs
- **Challenge**: The greedy longest-match algorithm in `ModernBERTTokenizer` operated across Swift substring grapheme clusters, resulting in $O(L^3)$ execution times on long unspaced sequences, susceptible to algorithmic denial of service.
- **Solution**: Constrained candidate subword window length to 64 characters. This bounds the inner loop to a constant upper factor, transforming pathological performance into linear time proportional to input length.

### 3. Preserving Rubric Probability Mass Distributions
- **Challenge**: OpenAI Decisions API returns rubric levels with arbitrary human-readable label strings. When adapted to `SystemOneAnswer`, mapping probability keys to labels broke `ScoreValue` parsing, which expects integer index strings corresponding to rubric levels.
- **Solution**: Partitioned wire data: numeric level values (`"0"`, `"1"`, etc.) are assigned as keys in `probabilities`, while descriptive labels are stored in `legend`, ensuring both full mathematical distribution integrity and UI readability.

## 📌 Key Decisions
1. **Zero-Tolerance Principle 7 Enforcement**: All synthetic mocks and fake evaluation bypasses were completely excised from example applications and benchmark tools. Examples now strictly fail fast with remediation instructions.
2. **Fail-Closed Security Posture**: Image validation and proxy transports fail closed by default—unverified image headers throw execution errors, and unencrypted HTTP is forbidden outside loopback interfaces.
3. **ModernBERT Control Token Sanitization**: Control tokens are explicitly stripped from prompt and option strings to safeguard against prompt injection and attention mask corruption.
4. **Strict Concurrency Compliance**: Long-running Core ML execution is isolated from the Swift concurrency cooperative thread pool, mock backends are thread-safe via lock synchronization, and caller configurations are protected against mutation.
